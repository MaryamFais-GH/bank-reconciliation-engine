# 🏦 Automated Bank Reconciliation Engine

A full-stack automated financial reconciliation engine built with Python, PostgreSQL, and Streamlit.

## Features
- Automated transaction matching between internal ledgers and bank statements.
- Identification of status: EXACT_MATCH, AMOUNT_MISMATCH, MISSING_IN_LEDGER, MISSING_IN_BANK.
- Interactive Streamlit dashboard for real-time anomaly filtering.

## Tech Stack
- **Database:** PostgreSQL
- **Data Processing:** Python, Pandas, SQLAlchemy
- **Frontend Interface:** Streamlit
